# 绣忆 · Unfinished Dowry

> 一段会随你一同遗忘的绣事。2D 手绘风叙事解谜游戏（Web）。
> 参赛：全国大学生数字媒体科技作品及创意竞赛 · 自主命题（虚拟现实VR与游戏方向）

一位苏绣绣娘在为女儿绣嫁衣的过程中渐渐遗忘一切。这个游戏最残忍也最温柔的地方在于：**它会和你一起遗忘**——你收集的记忆、甚至你的存档，都会随着剧情一针一针被拆掉。

## 运行方式

**双击 `index.html` 即可游玩**（纯前端实现，无需安装、无需联网、无需本地服务器）。

推荐使用 Chrome / Edge 浏览器。存档自动保存在浏览器本地（localStorage）。

📦 `docs/绣忆_演示视频.mp4`：约 2 分钟演示视频（720p，含合成配乐与旁白字幕），覆盖标题缝字 → 序章雨夜 → 引线解谜（含断线演示）→ 堂屋探索 → 女儿回家 → 人脸变绣绷 → 拆线溶解 → 相册扰动 → 数据尾声全流程。正式参赛前建议按 `docs/演示视频脚本.md` 用 OBS 重录带解说的版本。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标点击 / 空格 / 回车 | 推进对话；对话进行中按下=立即显示全文 |
| 鼠标拖拽 | 引线解谜：从 ◉ 起针，依次穿过针眼 |
| Esc | 打开 / 关闭记忆相册 |
| 设置面板 | 认知友好模式（大字/慢速/无震颤）、自动播放、静音、清除存档 |

## 四大核心机制（对应答辩创新点）

1. **拆线 = 遗忘**：章节末整个场景沿刺绣针脚溶解（`js/dissolve.js`），前沿是一道行进的行缝，线头四散飘落。
2. **存档即遗忘**：收集的记忆在章节末被"拆改"（`js/album.js`）——文字改写、影像褪色、原文以红色删除线鬼影残留。结局文案由玩家断线次数决定。
3. **交互即症状**：剧情推进中语言逐章破碎——绣云的台词出现"错字闪现后修正"的病程打字机（forget≥0.35 启用），对话选项逐渐"脱线"成残句缺字（悬停可见全文）；"认知友好模式"提供无障碍开关。
4. **起针教学**：核心玩法"引线解谜"（`js/puzzle.js`）将临床量表中的时钟描绘/连线测验转化为沿针眼引线的一笔绣谜题，线绷太紧会断。

## 人物立绘系统（v0.4 新增，v0.5 国漫风重制）

程序化国漫风半身立绘 + 参数化表情（`js/actor.js` + `art.js` 表情引擎），左/中/右三站位调度，说话人高亮、非说话人压暗，呼吸微动 idle 动画：

| 角色 | 表情 |
|---|---|
| 绣云 xiuyun | calm 平静 / smile 微笑 / focus 专注 / confuse 迷惘 / vacant 失神 / sad 哀伤 |
| 念念 niannian | normal 平静 / smile 微笑 / worried 担忧 / hurt 委屈 / cry 落泪 |

**国漫语汇**：大而有神的眼睛（上睫毛翼线 + 琥珀虹膜 + 双高光）、分层发型（刘海/侧发/发丝高光/呆毛）、绣云的银发玉簪标志物；全程序化生成，风格与水墨画面统一。
**病程渲染**：绣云的立绘随 `game.forget` 等级（章节推进而升高）逐渐"被拆线"——墨线震颤、笔画脱针缺口、去饱和、虹膜失去高光，病程深时抬臂的手褪为一道绣线轮廓，为"人脸变绣绷"埋下视觉伏笔。

## 技术实现要点

- **零依赖纯前端**：10 个 JS 模块，无任何框架/素材文件，双击即玩
- **程序化水墨×刺绣渲染**（`js/art.js`）：宣纸噪点纹理、抖动墨线、缎面绣针脚（双层短针+高光）、绣针光标、缝字标题动画，全部由 Canvas 代码生成；静态背景离屏缓存 + 季节着色（春绿/夏金/秋褐/冬灰）+ 粒子层（夏夜光斑/秋落叶/冬雪）
- **国漫风参数化表情引擎**（`art.js`）：睫毛翼线/虹膜双高光/眼睑褶/鱼尾纹等部件级参数，驱动立绘与头像的 11 种表情
- **Web Audio 全合成配乐**（`js/audio.js`）：Karplus-Strong 拨弦（古筝音色）、滤波噪声雨声、五声音阶主题旋律；引线音效经"激励平滑+低通+淡入"柔化处理，温润不刺耳；"配器即遗忘"——章节末旋律逐音符消失
- **数据驱动剧本**（`js/story.js`）：19 种节拍类型（bg/card/say/choice/puzzle/memory/facehoop/dissolve/album/titlecard/goto/flag/music/wait/show/clear/letter/phone/flashback/forget/shake），加新章节只需追加数组

## 手绘素材替换管线（美术升级路径）

程序化画面是"保底完成度"。要替换为手绘素材，只需把图片放入对应目录，同名即自动覆盖程序化画面：

**场景背景**（放入 `assets/img/`，1280×720）：

| 文件名 | 用途 |
|---|---|
| `rain.png` | 序章雨夜小镇 |
| `hoop.png` | 绣绷特写（教学谜题背景） |
| `room.png` | 堂屋主探索场景 |
| `photowall.png` | 照片墙 |
| `dress.png` | 红嫁衣 |
| `silk.png` | 标题缎面背景 |
| `black.png` | 黑幕纹理 |

**人物立绘**（放入 `assets/img/actors/`，透明背景，底边与画面下缘对齐）：

| 文件名 | 说明 |
|---|---|
| `xiuyun_calm.png` 等 | 绣云 × calm/smile/focus/confuse/vacant/sad |
| `niannian_normal.png` 等 | 念念 × normal/smile/worried/hurt/cry |

> ⚠️ 当前仓库内已内置一套网络下载的免抠素材作为**占位立绘**（`assets/img/actors/`，同一张图复制到全部表情位，故 PNG 生效期间表情切换不生效；`_xy.png`/`_nn.png` 为母版）。**该素材来自图片搜索、授权状态未知，仅限本地测试**——正式提交参赛前务必替换为自主创作或已获授权的立绘，否则存在版权风险。删除对应 PNG 即自动回退到程序化立绘（表情系统随之恢复）。立绘绘制高度可在 `actor.js` 的 `PNG_H` 表按角色微调。
>
> PNG 素材同时驱动：**对话框头像**（头部裁切圆形呈现，`drawAvatar`）、**相框老照片**（堂屋与照片墙，自动加做旧色调）、**"人脸变绣绷"演出**（淡出的脸与相框照片精确对位）。头部裁切位置在 `actor.js` 的 `PNG_HEAD` 表调整；素材就绪后背景缓存自动失效重绘。

图片加载成功自动替换对应画面；删除图片即恢复程序化绘制。头部表情细节可扩展 `art.js` 中的 `inkFace` 参数表。

## 代码结构

```
xiuyi/
├── index.html          入口（双击运行）
├── css/style.css       画布居中缩放
├── assets/img/         手绘素材替换目录（可空；actors/ 为立绘）
├── docs/               参赛文档（作品说明、演示视频脚本）
└── js/
    ├── util.js         数学/缓动/噪声/贝塞尔
    ├── audio.js        Web Audio 合成配乐与音效
    ├── art.js          程序化水墨与刺绣渲染（含参数化表情引擎）
    ├── actor.js        人物立绘系统（站位/表情/病程渲染/PNG 管线）
    ├── story.js        剧本/热点/记忆/谜题数据
    ├── puzzle.js       引线解谜
    ├── album.js        记忆相册 + 存档扰动（存档 v2，兼容 v1）
    ├── dissolve.js     拆线溶解
    ├── game.js         状态机（标题/剧本播放器/探索/设置）
    └── main.js         引导、缩放、主循环、输入分发
```
