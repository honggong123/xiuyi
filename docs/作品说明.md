# 《绣忆》Unfinished Dowry · 作品说明

**参赛类别**：全国大学生数字媒体科技作品及创意竞赛 · 自主命题 · 虚拟现实VR与游戏
**作品形态**：2D 手绘风叙事解谜游戏（Web，双击即玩，支持在线 WebGL 部署）
**开发方式**：团队协作开发（人工智能辅助代码与文案，人工负责创意、叙事结构与验收）

---

## 一、创作缘起

调查显示，中国阿尔茨海默病及相关痴呆患者已近 1700 万，60 岁以上轻度认知障碍患者约 3877 万；轻度患者就诊率仅 14%，47% 的家人以为那只是"年纪大了"。

多数严肃游戏讲述遗忘，玩家始终是安全的旁观者。《绣忆》想做的更进一步：**让游戏系统本身患上遗忘**。我们不满足于"讲一个关于遗忘的故事"，而是让玩家亲身经历"自己的记忆不可靠"这件事。

绣，是本作的 cultural anchor：苏绣讲究"密接其针，线行若游丝"，一针错了就要拆线重来——而记忆错了，没有重来的机会。母亲为女儿绣嫁衣、以"未完成的嫁衣"承载两代人的告别与接续，是中国家庭情感最含蓄也最锋利的意象。

## 二、核心创意：机制即隐喻

| 创新点 | 设计 | 落点 |
|---|---|---|
| ① 拆线=遗忘 | 章节末场景沿真实针脚路径溶解，NPC 之脸退化为未绣完的空绷 | 拆线溶解渲染（自定义前沿裁剪+线头粒子系统） |
| ② 存档即遗忘 | 颠覆"存档=可靠记忆"的游戏百年惯例：收集的记忆被悄悄改写、褪色，原文仅剩删除线鬼影；结局由玩家保全的记忆决定 | 对叙事数据施加受控扰动的工程实现 |
| ③ 交互即症状 | 对话选项随病程逐渐破碎（完整句→错名→残句），玩家亲历找词困难；提供"认知友好模式"无障碍开关 | 叙事节奏×UI 状态耦合 |
| ④ 引线解谜 | 将临床连线/时钟描绘测验转化为"沿针眼引线"的一笔绣谜题，线绷太紧会断（断线次数写入结局） | leash 张力机制的原创玩法 |

一句话：**别的游戏让你"看"一个遗忘的故事，我们让游戏系统本身患病——存档会背叛你，选项会离弃你，她也会认不出你。**

## 三、叙事结构

江南小镇，苏绣手艺人沈绣云为女儿念念绣嫁衣，却渐渐认不出丝线颜色、叫错女儿的名字。游戏按四季推进（本次提交：序章+春章完整可玩，约 30–40 分钟），母女双视角交替：

- **序章·雨夜**：缝字标题、教学谜题"海棠"，建立"针脚齐整，一丝不乱"的基线
- **春·堂屋**：自由探索 6 处记忆热点（顶针/笸箩/纸袋/电话/照片墙/绣绷），收集记忆、完成"并蒂莲""牡丹"两段引线谜题；女儿的归来揭开第一道裂缝——她把念念叫成了"阿珍"
- **深夜**：全游戏视觉签名——母亲注视女儿满月照，照片中的脸渐渐变成一幅只绣了半双眼的空绷
- **章末**：整个堂屋被一针一针拆开；记忆相册中"电话号码"与"满月照"被红线拆封改写——玩家第一次发现，**自己的记忆也不保了**
- **尾声**：克制的真实数据落版 + 一句行动号召："今晚，给家里打个电话。"（结局文案随玩家断线次数变化）

## 四、艺术表现

- **程序化水墨×刺绣美学**：宣纸噪点、抖动墨线、双层缎面绣针脚、绣针光标、以针线"缝出"的标题字——全部由代码生成，形成统一的"绣在缎面上的世界"视觉语言
- **人物立绘系统**：水墨淡彩半身立绘（绣云六态 / 念念五态，共 11 张表情立绘），与画面水墨语言统一；说话人高亮调度、呼吸微动；绣云的立绘随病程"被拆线"——去饱和、墨线震颤、脱针缺口，为"人脸变绣绷"埋下视觉伏笔
- **色彩即病程**：四季饱和度递减；**配器即遗忘**：五声音阶主题旋律在章节末逐音符消失，最后只剩雨声
- 手绘素材替换管线预置：场景画置入 assets/img/、立绘置入 assets/img/actors/ 即自动替换对应画面（程序化画面保底完成度，手绘升级无缝接入）

## 五、技术实现

零依赖纯前端（原生 Canvas 2D + Web Audio），10 个 JS 模块约 3900 行，双击即玩：

- 自研"缎面绣渲染器"（重采样针脚排布+高光丝线）
- 人物立绘系统（参数化水墨表情引擎 + 站位调度 + 病程渲染，PNG 立绘可无缝替换）
- 溶解引擎（噪声前沿裁剪+物理线头粒子）
- 数据驱动剧本机（21 种节拍类型，章节可持续扩展）
- Karplus-Strong 物理建模合成古筝音色（无音频素材文件）
- localStorage 存档（含记忆损坏状态与病程等级的序列化，旧档自动迁移）

全流程经实机自动化测试验证：三段引线谜题、双选择分支、存档扰动、溶解演出、结局回收，零运行时错误。

## 六、社会价值

- 以"体验式共情"替代"数据式科普"：让玩家（尤其年轻玩家）理解轻度认知障碍的隐匿病程与家庭处境
- 片尾联动真实数据与行动号召，可对接社区认知筛查公益宣传
- "认知友好模式"本身即是无障碍设计示范——游戏不仅讲认知障碍，也对认知障碍玩家友好

## 附录一：操作说明

| 操作 | 效果 |
|---|---|
| 鼠标点击 / 空格 / 回车 | 推进对话；对话进行中按下 = 立即显示全文 |
| 鼠标拖拽 | 引线解谜：从 ◉ 起针，依次穿过针眼 |
