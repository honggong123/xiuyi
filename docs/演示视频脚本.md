# 《绣忆》演示视频脚本（3 分 30 秒）

> 录制准备：Chrome 全屏 1920×1080；设置里开"自动播放"可挂机过场，谜题环节切回手动实机操作；系统音量开（配乐是合成古筝+雨声，是卖点）。
> 录制工具建议：OBS Studio（免费）。素材替换为手绘后重录一遍即可升级全片质感。

## 分镜拍摄要点

- 镜头 3、4、7 必须实机录制（展示真实交互），其余可用"自动播放"挂机
- 镜头 6 前留 1 秒黑场静默，让"人脸变绣绷"自己说话
- 断线演示（镜头 3）故意拖到断一次：展示"游戏在记录你的失误"
- 全片色调已随章节自动变化，无需调色

## 现场答辩 3 分钟演示动线（备用）

标题缝字(20s) → 谜题实机让评委/观众上手(60s) → 直跳深夜人脸绣绷：`story.js` 中 NIGHT 段可单独提取为演示模式(40s) → 相册扰动对比(30s) → 尾声(30s)
